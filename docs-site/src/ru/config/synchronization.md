# synchronization.yml

Две системы синхронизации: **roles** отражает группы LuckPerms на роли Discord, **nickname** устанавливает никнеймы Discord из имён Minecraft. Обе двусторонние — роли назначаются и снимаются при изменении групп.

Требуется Vault и LuckPerms на сервере (для определения групп).

## Главный выключатель

```yaml
enabled: true
```

Установите `false`, чтобы отключить все системы синхронизации одновременно.

## roles

```yaml
roles:
  enabled: true
  interval: 30
  mapping:
    verified: "1521342858945101894"
    # testing: "ROLE_ID_HERE"
    # vip: "ROLE_ID_HERE"
```

| Поле | Тип | Описание |
|------|-----|----------|
| `enabled` | Булево | Включить синхронизацию ролей |
| `interval` | Целое | Как часто проверять и синхронизировать (секунды) |
| `mapping` | Map | Имя группы LuckPerms → ID роли Discord |

Ключ маппинга — имя группы LuckPerms, значение — ID роли Discord. Когда привязанный игрок имеет сопоставленную группу LuckPerms, бот назначает соответствующую роль Discord. Когда группа удаляется (или игрок отвязывается), роль снимается. Каждый игрок может иметь несколько ролей из нескольких сопоставленных групп.

## nickname

```yaml
nickname:
  enabled: true
  interval: 30
  format: "%player_name%"
```

| Поле | Тип | Описание |
|------|-----|----------|
| `enabled` | Булево | Включить синхронизацию никнеймов |
| `interval` | Целое | Как часто проверять и обновлять (секунды) |
| `format` | Строка | Формат никнейма |

Поле `format` поддерживает плейсхолдер `%player_name%`. Бот устанавливает никнейм Discord каждого привязанного участника в соответствии с разрешённым форматом при каждом цикле синхронизации.
