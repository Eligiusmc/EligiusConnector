# counters.yml

Динамически переименовывает голосовые/текстовые каналы Discord. Два типа: **periodic** (по интервалу) и **state** (по событиям сервера).

## Встроенные плейсхолдеры

| Плейсхолдер | Описание |
|-------------|----------|
| `%server_online%` | Текущие игроки онлайн |
| `%server_max_players%` | Максимальные слоты сервера |
| `%server_unique_joins%` | Всего уникальных игроков заходило |
| `%server_ram_used%` | Использовано ОЗУ (МБ) |
| `%server_ram_free%` | Свободно ОЗУ (МБ) |
| `%server_ram_total%` | Всего ОЗУ (МБ) |
| `%server_uptime%` | Время работы сервера |
| `%server_members%` | Количество участников сервера Discord |

## periodic

Обновляет название канала каждые N секунд, используя строку формата с плейсхолдерами.

```yaml
counters:
  online_players:
    type: periodic
    enabled: true
    channel: "1521280346585305268"
    format: "🟢 Онлайн: %server_online%"
    interval: 30
```

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | Строка | Должно быть `periodic` |
| `enabled` | Булево | Включить этот счётчик |
| `channel` | Строка | ID канала Discord для переименования |
| `format` | Строка | Название канала с плейсхолдерами |
| `interval` | Целое | Интервал обновления в секундах |

### Устранение дребезга и кулдаун

Для избежания ограничений частоты Discord, переименования каналов имеют механизм устранения дребезга: если результирующее имя не изменилось, переименование пропускается. Дополнительно применяется кулдаун в 120 секунд между переименованиями одного канала. Высокочастотные счётчики (например, `interval: 5`) будут переименовывать канал только при реальном изменении значения.

## state

Реагирует на изменения состояния сервера — переименовывает канал немедленно при смене состояния.

```yaml
counters:
  server_status:
    type: state
    enabled: true
    channel: "1521276573033173204"
    state_key: server_online
    states:
      online: "🟢 Онлайн"
      offline: "🔴 Офлайн"
```

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | Строка | Должно быть `state` |
| `enabled` | Булево | Включить этот счётчик |
| `channel` | Строка | ID канала Discord для переименования |
| `state_key` | Строка | Отслеживаемое наблюдаемое состояние (`server_online`) |
| `states.online` | Строка | Название канала, когда состояние `true` |
| `states.offline` | Строка | Название канала, когда состояние `false` |

## ⚠️ Совместное использование канала server_status

Счётчик `server_status` использует тот же `channel`, что и `status.yml`. Счётчик переименовывает канал, а `status.yml` публикует эмбед онлайн/офлайн. Всегда держите их синхронизированными — изменение канала в одном файле требует изменения в другом.
