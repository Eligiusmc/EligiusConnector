# console.yml

Двусторонний консольный мост: логи сервера транслируются в канал Discord, а сообщения, введённые в этом канале, выполняются как команды сервера (если не в чёрном списке).

## channel

```yaml
channel: "1521272226442383440"
```

ID канала Discord. Все логи сервера транслируются сюда. Сообщения, отправленные пользователями в этом канале, выполняются как команды сервера Minecraft.

## poll_interval

```yaml
poll_interval: 2
```

Как часто (в секундах) плагин читает новые строки из `logs/latest.log`. Меньшие значения дают более близкий к реальному времени вывод ценой немного более высокой загрузки ЦП.

## command_blacklist

```yaml
command_blacklist:
  - "stop"
  - "restart"
  - "reload"
  - "ban"
  - "ban-ip"
  - "pardon"
  - "pardon-ip"
  - "op"
  - "deop"
  - "say"
  - "gamemode"
  - "whitelist"
  - "kick"
  - "plugins"
```

Команды из этого списка не могут быть выполнены из Discord. Проверка основана на префиксе — например, блокировка `ban` также блокирует `ban-ip` и `banlist`, но явная запись `ban-ip` обеспечивает ясность. Опасные административные команды (stop, restart, op, deop) находятся в чёрном списке по умолчанию.

## Форматирование

Вывод логов в Discord использует блоки кода ` ```ansi ` для сохранения ANSI-кодов цветов из консоли сервера, придавая нативный консольный вид.
