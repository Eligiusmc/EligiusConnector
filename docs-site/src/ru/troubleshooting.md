# Устранение неполадок и частые ошибки

## 🔴 Проблемы с токеном бота

**Ошибка:** `Bot token not configured!`

Укажите токен вашего Discord-бота в `config.yml`:
```yaml
bot:
  token: "ВАШ_ТОКЕН_СЮДА"
```

**Ошибка:** `Failed to initialize Discord`

Проверьте:
- Токен указан верно (без лишних пробелов)
- Необходимые интенты включены в Портале разработчика Discord
- Бот приглашён на ваш сервер

## 🔴 Ошибки базы данных

**Ошибка:** `no such column: '...'`

Удалите `plugins/EligiusConnector/connector.db` и перезапустите сервер. Плагин пересоздаст базу данных с правильной схемой. **Это приведёт к потере данных привязанных аккаунтов.**

## 🔴 Проблемы с верификацией

**Ошибка:** `Invalid code or expired`

Коды истекают через 5 минут. Сгенерируйте новый код, нажав кнопку **Verify** в Discord.

**Ошибка:** `Account already linked`

Ваш Discord-аккаунт уже привязан к аккаунту Minecraft. Сначала используйте `/unlink`.

## 🔴 Ограничения частоты запросов

**Симптом:** Счётчики не обновляются, статусные эмбеды не появляются

Discord ограничивает частоту API-вызовов. Если вы часто перезапускаете сервер для тестирования, подождите 2-3 минуты между перезапусками, пока лимиты не истекут. В продакшене с нормальным аптаймом это не проблема.

## 🔴 Модуль не работает

**Симптом:** Модуль (чат, верификация и т.д.) отключён

Проверьте:
1. YAML-файл модуля существует в `plugins/EligiusConnector/`
2. Поле `channel:` содержит действительный ID канала Discord (не плейсхолдер `CHANNEL_ID`)
3. Модуль показывает `ENABLED` в консольном логе запуска

## 🔴 Кнопка экономики показывает "Недоступно"

Установите **Vault** и **EssentialsX**. Кнопка экономики требует экономический плагин, совместимый с Vault.

## 🔴 Плейсхолдеры отображаются как текст

Установите **PlaceholderAPI**. Без него `%player_name%`, `%server_online%` и подобные плейсхолдеры не будут обработаны.
